3. Core Component Requirements (Based on screen.png)
A. App Layout & Navigation
Build a Top Navigation Bar with the brand logo (Barlow, Pitch Green), center navigation links (Player Showcase, Scouting Hub, Coach Dashboard), a search input, and profile controls.

Implement a layout wrapper that contains the main content area and a fixed left-sidebar for filters.

B. Scouting Hub: Left Sidebar (Advanced Filters)
Build controlled components bound to the global state:

Age Slider: Dual-thumb or single-thumb range slider (16-35).

Position Checkboxes: GK, DF, MF, FW.

Min AI Score Slider: Float values (e.g., 7.5), styled with the Tactical Blue accent.

Action: Changing these filters must instantly update the Player Grid on the right.

C. Scouting Hub: Main Canvas
AI Smart Matches (Carousel): * Implement a horizontally scrollable container (snap-x, hidden scrollbar).

Cards must have a glowing effect (shadow-[0_0_15px_rgba(0,176,255,0.3)]) and display the matchPercentage badge.

Player Grid:

Responsive grid (grid-cols-1 md:grid-cols-2 xl:grid-cols-4).

Card Anatomy: Player avatar, Name, Position, Age, Team. A 3-column mini-stat grid (e.g., PAC, PAS, DEF). A prominent "AI Overall" score.

Interaction: Each card has a top-right Checkbox. Clicking it adds the player to the ComparisonSelection state array. If selected, change the card's inner border/background slightly to Tactical Blue (bg-tactical-blue/5).

D. Comparison Matrix Drawer (Crucial UX)
Build a fixed drawer at the bottom of the screen (absolute bottom-0 left-0 right-0).

Animation: It must translate into view (translate-y-0) ONLY when ComparisonSelection.length > 0. Otherwise, it stays hidden off-screen (translate-y-full).

Matrix Logic: * Compare up to 3 selected players side-by-side.

Rows: Overall Rating, Sprint Speed, Shot Power, Passing Acc.

Conditional Formatting: Write a utility function that finds the highest value in each row and colors that specific text in Pitch Green (#00E676), leaving the others in white.
